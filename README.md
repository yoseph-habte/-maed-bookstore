# Maed (ማእድ) Bookstore
A responsive, interactive frontend bookstore web application built as part of the frontend development camp. ማእድ (Ma'ad) serves as a gathering place for readers, offering a seamless browsing and shopping experience.

## ✨ Features
* **Home Page:** Features an inviting literary hero banner with a library background, navigation links, and handpicked featured titles.
* **Book Catalog:** Includes a complete inventory grid with a dedicated category filter sidebar (Fiction, Technology & Code, Art & UI/UX Design).
* **Live Search:** Real-time search bar that filters books instantly by title or author as you type.
* **Interactive Shopping Cart:** Dynamic cart counter that updates instantly when items are added and persists across pages using browser `localStorage`.
* **Fully Responsive:** Styled using CSS Grid and Flexbox for seamless viewing on desktops, tablets, and mobile devices.

## 🛠️ Tech Stack
* **HTML5** for semantic markup and structure
* **CSS3** (Custom Properties, Flexbox, Grid) for modern styling and typography (`Playfair Display` and `Poppins`)
* **JavaScript (ES6)** for DOM manipulation, live search, filtering logic, and cart state management
* **Git & GitHub** for version control and team collaboration
